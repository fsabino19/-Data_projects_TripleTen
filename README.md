# -Data_projects_TripleTen
Projects I worked on while attending the Data Science TripleTen Bootcamp.


| Project number | Title | Description | 
| :-----------: | ----------- |----------- |
| 1 | [Megaline Sales Analysis](https://github.com/fsabino19/Megaline-Sales-Analysis.git) | Analyzed Megaline mobile plans to uncover revenue trends. Found Ultimate users generate more consistent income, while Surf users exceed limits. Recommended marketing shift toward Ultimate and pricing updates for Surf to align with usage and reduce churn.|
| 2 | [Instacart](https://github.com/fsabino19/Instacart-Data-Project.git) | The project task was to prepare a report that gives insight into the shopping habits of Instacart customers |
| 3 |[ Machine Learning: Plan Recommendation](https://github.com/fsabino19/Model-Building-for-Megaline-s-Smart-or-Ultra.git) | This project aims to develop a machine learning model for Megaline and the goal is to build a model that accurately recommends the most suitable plan for each subscriber |
| 4 |[Video Games Sales Forecasting](https://github.com/fsabino19/Video-Game-Sales-Forecasting) | Analyzed global video game sales to identify platform, genre, and regional trends. Found PS2 and RPGs led in total sales, while Action and Sports games performed best in NA and EU. Delivered data-driven marketing recommendations for Ice’s 2017 campaign based on user ratings and cross-platform success. |
| 5 |[Supervised Learning: Customer Churn Prediction](https://github.com/fsabino19/Building-a-Model-to-predict-Beta-Bank-customers.git) | Predict customer churn for Beta Bank using historical behavioral data and this is a binary classification task where the target variable 'Exited' indicated whether a customer left(1) or stayed(0) |
| 6 |[Machine Learning in Business: Oil Well Profitability Analysis](https://github.com/fsabino19/-OilyGiant.git) | This project focused on using regression modeling and statistical analysis to help an energy company make a high‑stakes business decision about where to develop its next oil well. |
| 7 |[Integrated Project: Gold Recovery](https://github.com/fsabino19/Integrated-Project-Gold-Recovery.git) | This project focused on analyzing industrial process data from a gold recovery operation and building predictive models to estimate recovery efficiency at different stages of production.
